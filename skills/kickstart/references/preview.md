# Showing the design system

A tokens file can't be looked at. Every time design tokens are created or changed, end by showing them as a page: colors in light and dark with their contrast, type, spacing, sizes, radii, shadows and motion. The page is generated by the script, so it costs no writing and is always in step with the tokens.

## Local page (always)

`design/build_tokens.py` is the plugin's tool, copied into the project. If the project's copy has no `preview` command (`python3 design/build_tokens.py --help`), it predates this plugin version: replace it with `cp <plugin>/skills/kickstart/scripts/build_tokens.py design/build_tokens.py`, and say so in the report. Here `<plugin>` is the directory two levels above this skill's.

```bash
python3 design/build_tokens.py preview design/tokens.json --out design/preview.html --title "<Project name> Design System" [--css <font stylesheet> ...]
```

- `--css` takes the stylesheets that load the project's fonts, relative to `design/`. Fontsource: `../node_modules/@fontsource/<font>/index.css` or `../node_modules/@fontsource-variable/<font>/index.css`. Without them, the page uses the fallback fonts.
- `design/preview.html` is generated output. The base `.gitignore` already ignores it.

## Published page (when you can publish HTML)

If you have a tool that publishes an HTML page and returns a link (Claude Artifacts: the `Artifact` tool), publish the preview there too, so the user can open it with one click.

1. Generate a host-ready copy outside the repo:
   `python3 design/build_tokens.py preview design/tokens.json --out <tmp>/index.html --title "<Project name> Design System" --google-fonts --fragment`
   - `--fragment` leaves out the document wrapper that the host adds itself.
   - `--google-fonts` loads the font families from Google Fonts, because such hosts block other stylesheets.

   The page already follows the Artifact page contract (title, theme tokens with dark mode, safe-area gutters), so publish it as it is. Follow the tool's own publishing steps, and give it a generic `icon` such as `palette`.
2. Publish it privately. Write the link into `docs/DESIGN.md`, on the line `Preview: <link>`, so later runs republish to the same link instead of creating a new one.
3. A later run (sync, adopt, a token edit) republishes to that link, after reading the artifact if the tool requires it.

If a font isn't on Google Fonts, say that the published page shows its fallback, and that `design/preview.html` shows the real font.

## Tell the user

End with the link, or the file path when there's no link (`open design/preview.html` on macOS). Add one line on what the page shows. If the published copy can't be made, give the path and say why; don't silently skip it.
